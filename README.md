# GFL2 Packet CSV Exporter

소녀전선2의 로그인 데이터를 CSV로 저장하는 Windows용 도구입니다. 보유 인형, 장비, 재화, 제대 등의 계정 정보를 게임 밖에서 확인하거나 GF2Tools와 같은 외부 도구에서 활용할 수 있습니다.

## 주요 기능

- 인형, 무기, 부착물, 공용키, 리몰딩, 아이템, 제대 정보 수집
- 숙소·아바타, 지원소대 설정·편성·소자, 계정 진행도·업적 수집
- 인형 육성, 결합도, 스킬 및 장비 상태 저장
- 로그인 데이터 12종 수집 진행 및 해독 결과 표시
- CSV 자동 저장, ZIP 백업 및 업데이트 확인

## 사용 방법

1. [Releases](https://github.com/Kimbyeoungjang/GF2-csv_exporter/releases)에서 Windows용 ZIP을 다운로드하고 압축을 풉니다.
2. `GFL2-Packet-CSV-Exporter.exe`를 실행합니다.
3. **캡처 시작**을 누르고 관리자 권한 요청을 승인합니다.
4. **캡처 준비 완료**가 표시되면 소녀전선2에 로그인합니다.
5. 수집이 완료되면 백업이 자동으로 저장됩니다. 완료 안내를 확인하면 게임과 Exporter가 종료됩니다.

이미 게임에 로그인한 상태라면 게임을 종료한 후 다시 진행해 주세요.

## 저장 파일

| 파일 | 내용 |
| --- | --- |
| `gfl2_user_csv_bundle.zip` | 정상 완료된 계정 백업 (기본 CSV 44종, 능력치·장비 상태 CSV 2종, JSON 2종) |
| `GFL2-Exporter-Log_*.txt` | 정상 완료 작업 로그 |
| `gfl2_packet_backup/` | 개별 CSV, 미완료 백업 및 진단 파일 |

백업 ZIP은 실행 파일이 있는 폴더에 저장됩니다. 추가 상태 CSV 생성에 실패하면 기본 백업은 유지됩니다.

12종 수집·해독이 완료되지 않으면 부분 백업으로 저장하며, 기존 정상 백업을 덮어쓰거나 게임을 종료하지 않습니다. 수집이 진행되지 않는 경우 게임을 종료하고 캡처부터 다시 시작해 주세요.

## 보안 및 개인정보

소녀전선2 프로세스가 서버에서 수신하는 패킷의 복사본만 읽으며 게임 패킷을 전송하거나 수정하지 않습니다. WinDivert를 사용하는 캡처 보조 프로그램에만 관리자 권한이 필요합니다.

디버그 진단 저장은 기본적으로 꺼져 있습니다. 활성화해도 패킷 원문이나 IP, 포트, 로그인 인증 정보 대신 진단용 메타데이터만 저장합니다. 계정 백업에는 보유 장비와 재화, 장비 식별값 등 개인 게임 데이터가 포함됩니다. 작업 로그와 진단 ZIP도 수집 규모 및 시각을 포함하므로 공개 공유에 주의해 주세요. 소스 실행 시 생성되는 `logs/startup.log`에는 설치 경로 등이 포함될 수 있습니다.

## 소스 실행 및 빌드

Python 3.11~3.13이 필요합니다.

- 소스 실행: `start_packet_csv_exporter.bat`
- EXE 빌드: `build_exe.bat`

배포용 소스 ZIP 생성: `python packaging/public_source.py GFL2-Packet-CSV-Exporter-v1.6.0-source.zip`

## 참조 데이터

캡처 전에 승인된 참조 데이터를 확인합니다. 인터넷 연결이 없거나 갱신에 실패하면 검증된 로컬 참조 데이터를 사용합니다. 이전 참조 팩은 `reference_data/versions/`에 보존하며, 백업 manifest에는 사용한 참조 데이터의 식별 해시를 기록합니다.

[GF2Tools API](https://github.com/Kimbyeoungjang/GF2Tools-api)의 `main` 브랜치에서 승인된 참조 팩만 가져옵니다. 최초 실행에도 승인된 내장 팩을 사용할 수 있습니다. 오프라인 사용을 강제하려면 실행 폴더에 빈 `reference_api_url.txt`를 만드세요.

## 참고 사항

참조 데이터만 바뀌면 자동 갱신할 수 있습니다. 패킷 구조나 해석 규칙이 바뀌면 Exporter 업데이트가 필요할 수 있습니다. 수집된 모든 데이터의 의미나 최종 능력치 계산이 확정된 것은 아닙니다.

이 프로그램은 소녀전선2의 개발사 및 운영사와 관계없는 비공식 도구입니다. 사용 전 게임 이용약관과 운영정책을 확인해 주세요. 프로그램은 보증 없이 제공되며 사용에 따른 책임은 사용자에게 있습니다.
